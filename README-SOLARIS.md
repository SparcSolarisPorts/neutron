# Neutron on Oracle Solaris 11.4 / SPARC64

The Solaris/SPARC port builds against the Firefox release and patch set
maintained by Oracle Solaris Userland:

https://github.com/oracle/solaris-userland/tree/master/components/desktop/firefox

Solaris/SPARC Firefox patches:

https://github.com/oracle/solaris-userland/tree/master/components/desktop/firefox/patches

Use `"solaris-sparc64"` in the application's `platforms` array.

Solaris-specific code is marked with `SOLARIS NOTE` comments.
